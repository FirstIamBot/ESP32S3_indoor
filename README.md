# Метеостанция LilyGo EPD 4.7" с OpenWeatherMap
Использование дисплея LilyGo EPD 4.7" для отображения данных о погоде с OpenWeatherMap

## Возможности
- Настройка WiFi через WiFiManager (не требуется прописывать данные в коде)
- Интеграция с OpenWeatherMap для прогноза погоды
- E-paper дисплей с низким энергопотреблением
- Режим глубокого сна для экономии батареи
- Автоматическая синхронизация времени через NTP

## Инструкция по настройке

### 1. Первоначальная настройка
1. Прошейте прошивку на ваш ESP32
2. При первом запуске устройство создаст WiFi точку доступа с именем **"ESP32_Weather"** и паролем **"12345678"**
3. Подключитесь к этой WiFi сети с вашего телефона или компьютера
4. Автоматически откроется портал настройки (или перейдите на `192.168.4.1`)
5. Выберите вашу домашнюю WiFi сеть и введите пароль
6. Нажмите "Save" - данные сохранятся в энергонезависимой памяти
7. Устройство перезагрузится и автоматически подключится к вашей WiFi сети

### 2. Настройка OpenWeatherMap
Отредактируйте файл `owm_credentials.h` и укажите:
- `apikey` - Получите бесплатный API ключ на [OpenWeatherMap](https://openweathermap.org/)
- `City` - Название вашего города
- `Country` - Код вашей страны (например, "UA", "US", "GB")
- `Language` - Язык описания погоды (например, "UA", "EN", "FR")
- `Hemisphere` - "north" или "south"
- `Units` - "M" для метрической или "I" для имперской системы
- `Timezone` - Строка вашего часового пояса (см. [базу данных POSIX timezone](https://github.com/nayarsystems/posix_tz_db/blob/master/zones.csv))
- `ntpServer` - Адрес NTP сервера (по умолчанию: "0.uk.pool.ntp.org")

### 3. Сброс настроек WiFi (при необходимости)
Если нужно изменить WiFi сеть или сбросить конфигурацию:
1. В файле `OWM_EPD47_epaper_v2.5.ino` раскомментируйте строку в функции `StartWiFi()`:
   ```cpp
   wm.resetSettings();
   ```
2. Прошейте прошивку
3. Устройство забудет сохраненную WiFi и снова создаст портал настройки
4. После настройки закомментируйте `wm.resetSettings();` обратно и перепрошейте

## Параметры конфигурации

### Настройки WiFiManager
- **Имя точки доступа**: ESP32_Weather
- **Пароль точки доступа**: 12345678
- **Таймаут портала настройки**: 180 секунд (3 минуты)
- **Таймаут подключения**: 30 секунд

### Управление питанием
- **Длительность сна**: 60 минут (настраивается через `SleepDuration`)
- **Час пробуждения**: 8:00 (настраивается через `WakeupHour`)
- **Час засыпания**: 23:00 (настраивается через `SleepHour`)

## Сборка
Проект использует PlatformIO. Для сборки:
```bash
platformio run
```

Для загрузки:
```bash
platformio run --target upload
```

## Примечания
- WiFi данные хранятся безопасно в энергонезависимой памяти ESP32
- Не нужно изменять код для смены WiFi сети - просто сбросьте настройки
- Устройство автоматически переподключится после отключения питания
- Обновления дисплея выравниваются по интервалам сна для максимального времени работы от батареи
